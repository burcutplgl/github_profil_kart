
💻 GitHub Kart
📌 Proje Hakkında

<p> GitHub kullanıcı adını aratarak kullanıcı bilgilerini, profil fotoğrafını, takipçi ve takip edilen sayılarını, public repository sayısını ve son repositorylerini gösteren dinamik bir web uygulamasıdır. </p>

🛠️ Kullanılan Teknolojiler
<p> HTML5 • CSS3 • JavaScript • Axios • GitHub REST API • Font Awesome </p>

✨ Özellikler
<ul> 
<li>🔎 GitHub kullanıcı adı ile arama</li>
 <li>👤 Profil bilgilerini görüntüleme</li> 
 <li>👥 Followers ve Following bilgilerini gösterme</li> 
 <li>📚 Public repository sayısını gösterme</li>
  <li>🔗 Kullanıcının repositorylerine doğrudan erişim</li>
 <li>⚠️ Hatalı kullanıcı aramalarında hata mesajı gösterme</li> 
</ul>

⚙️ API Kullanımı
<p> Proje, GitHub REST API üzerinden kullanıcı ve repository bilgilerini dinamik olarak almaktadır. API istekleri Axios kullanılarak gerçekleştirilmiştir. </p>

🎨 Tasarım
<p> Koyu tema, kullanıcı kartı yapısı, Font Awesome ikonları ve sade bir arayüz kullanılarak modern ve kullanıcı dostu bir tasarım oluşturulmuştur. </p>
